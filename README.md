# M365-Automation-Scripting-Toolkit
A curated collection of PowerShell scripts automating enterprise IT operations across the Microsoft 365 ecosystem — covering user lifecycle management (account lockdown, risky user remediation), identity security (MFA revocation, session invalidation, on-premises AD disablement), compliance (eDiscovery legal hold automation via Microsoft Purview), Teams governance (team provisioning, channel management, membership updates), Exchange Online administration (distribution list creation and configuration), and device management (Autopilot hardware hash capture and upload). Built for IT admins and automation engineers to adapt and deploy in their own environments.
